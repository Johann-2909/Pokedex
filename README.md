# Pokédex

A fully functional Pokédex built with Vanilla JavaScript, displaying all 151 original Pokémon with live API data.

## 🔗 Live Demo
[https://johann-2909.github.io/Pokedex/](https://johann-2909.github.io/Pokedex/)

## Features
- Displays all 151 original Pokémon
- Detail page per Pokémon with stats, abilities and Pokédex description
- Live search and type filter with combined logic
- Shiny toggle
- Data fetched via PokéAPI

## Tech Stack
- HTML
- CSS
- JavaScript
- PokéAPI / pokeapi-js-wrapper
